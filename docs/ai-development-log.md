# Журнал работы с ИИ

Дата: 4 ноября 2026, МСК. Реальные секреты и пароли не сохраняются.

| Этап | Запрос / решение | Проверяемый результат |
|---|---|---|
| V0 | Технический аудит существующего Dashboard, без изменений | Найдены общий API, отдельный защищённый режим, старый JSON и ограничения модели |
| V1 | Спроектировать самостоятельное приложение, не реализовывать | Согласованы стек, отдельная история, роли, серверное хранение и границы MVP |
| V2/A | Проверить зависимости перед переносом | Прочитаны конкретные password/migration/date/CSS части, исключён script.js целиком |
| V2/B | Создать независимую основу | FastAPI, Settings, SQLite helper, новая схема, страница, ES modules |
| V2/C | Проверить поведение и независимость | Временные project-local базы, API и реальный Uvicorn, Node-тесты |
| Исправление | Windows не освобождал SQLite/log в тестах | Явное закрытие sqlite connections; прямой запуск интерпретатора вместо venv redirector |
| Окружение | ensurepip и DNS в песочнице не сработали | Установка в новую .venv через системный pip с разрешённым сетевым доступом |
| V2/D | Документация и первый коммит | Документы, проверка staged-набора и секретов, локальный commit без remote |

Полный исходный запрос V2 находится в чате. Документы описывают реализованный объём,
а не выдают архитектурный план будущих модулей за готовые функции.
